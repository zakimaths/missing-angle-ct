# Post 1: Introducing the project

## LinkedIn

I built Missing-Angle CT, a browser-based tool for reconstructing CT cross-sections from X-ray projection measurements.

You can inspect individual views, watch them contribute to an image, change the angular coverage and compare the result with a reference. Refinement controls, error statistics and region labels help examine what changed. Experiments can be exported and recalculated.

The demo includes acquired measurements of Helsinki test objects, alongside simulated projections of real chest and abdominal CT images. That distinction is shown throughout the interface.

The attached recording shows a calculation using 360 acquired object views. The image is calculated in the browser as the views are processed.

Try it: https://zakimaths.github.io/missing-angle-ct/
Code and methods: https://github.com/zakimaths/missing-angle-ct

I would welcome feedback on the reconstruction workflow and the clarity of the comparisons.
