Purpose and workflow

This lab examines how measurement coverage and reconstruction choices affect a CT cross-section. It supports direct calculation from projection data, comparison with reference images, and reproducible assessment of errors and structural detail.

  1. Reconstruct. Select a measured dataset or import projections, choose the number and distribution of views, and run the calculation. Playback and single-view stepping expose the intermediate results.
  2. Assess. Compare the reconstruction with the reference, inspect local features, and review both image errors and agreement with measured rays.
  3. Compare conditions. Vary one setting at a time to separate the effects of view count, angular coverage and refinement. Export each run to preserve its inputs, results and annotations.
Terminology

View or projection: detector readings acquired at one angle. Each reading represents accumulated X-ray attenuation along a path through the object; reconstruction estimates how that attenuation is distributed within the cross-section.

Reference: an image used to assess the reconstruction. The real-object references were reconstructed by the dataset authors from full scans. They provide an independent method comparison, with their own measurement and reconstruction errors.

Attenuation: the reduction in X-ray intensity through material. Brighter pixels here represent higher estimated attenuation coefficients. Artifact: a streak, blur or false structure introduced by the acquisition or reconstruction process.

Acquisition and image settings: View count sets the measurement budget. Angular selection determines its distribution across the scan; a restricted range can leave structures poorly constrained. Image size sets the reconstruction grid. Increasing the number of pixels raises computational cost without necessarily improving recoverable detail.

Enhance and check the reconstruction

Additional correction passes can improve agreement with the measurements. Smoothing may reduce noise at the cost of edge sharpness and small-feature contrast. Compare the initial and refined results using the images and error metrics below.

Correction passes: Each pass revisits the selected projections, compares predicted and measured readings, and updates the image to reduce their disagreement. Additional passes reuse the existing data. Smoothing can suppress noise while reducing edge sharpness or feature contrast, so assess both local detail and the reported errors.

Reconstruction accuracy

Check the first pass against your current image. Lower RMSE and MAE mean smaller errors; bias tells you whether values are too high or too low. Correlation describes a relationship, not accuracy.

Interpreting the error metrics

RMSE (root mean square error) summarises differences while weighting larger errors more strongly. MAE (mean absolute error) is the average absolute difference. Zero means an exact match for the values being compared.

Bias is the average signed difference: positive means values tend to be too high, negative too low. Positive and negative errors can cancel; low bias alone does not establish accuracy.

Pearson r measures linear association. A correlation of 1 can coexist with systematic scaling or offset errors. Interpret it alongside RMSE, the fitted line and spatial differences.

Selected rays contribute to reconstruction updates. Unused rays assess agreement with measurements excluded from those updates. Image errors and ray errors compare different quantities; compare the first-pass and current values within the same row.

Measured versus predicted: paired data

The scatter plot pairs measured readings with values predicted from the reconstruction. The dashed diagonal denotes equality; points above or below it indicate overprediction or underprediction. The angular error plot identifies acquisition directions with greater disagreement. Systematic patterns can be informative even when an aggregate score is small.

Fitted relationship and prediction R²

The fitted line describes the linear relationship between measured and predicted readings; exact agreement has slope 1 and intercept 0. Prediction R² compares squared errors with a constant prediction equal to the mean measured reading. A value of 1 denotes an exact match, 0 the same squared error as that baseline, and a negative value a larger error. R² does not measure the proportion of anatomical detail recovered.

R² can be negative if predictions are worse than the mean reading. These are descriptive statistics: neighbouring rays are correlated, so no independence-based p-values are reported. Repeatedly tuning on unused views makes them a validation set, not a final blind test.

Example comparison protocol
  1. Reconstruct a real object using 90 views spread across the scan. Record the reference error and annotate a feature of interest. Export the run as a baseline.
  2. Retain 90 views and select Use the first angles only. This holds view count constant while changing angular coverage. Compare feature shape, contrast and directional artifacts.
  3. Apply three additional passes with light smoothing. Assess changes in reference error, unused-ray agreement and the annotated feature. Report improvements and degradations separately.

For a reproducible comparison, record the dataset, view selection, image size, refinement settings and display scale. Distinguish agreement with a reference reconstruction from agreement with the acquired measurements; the two criteria can favour different results.

The reconstruction export preserves a recalculable run. The CSV contains paired detector readings for external statistical analysis, and the error report records summary metrics and region measurements.

Bring your own projections

Imported projection data must include detector readings, acquisition angles and scanner geometry. Readings must be corrected and converted to attenuation line integrals. Download a sample dataset for a compatible example. The technical guide provides the full import specification.

The Mac app also accepts the original HTC2022 MATLAB files. Photographs, CT slices and ordinary DICOM image stacks are already images; they do not contain the required raw projection geometry.

Technical guide and methods

Source and what this experiment can tell you

The built-in tests are physical plastic objects scanned at the University of Helsinki. Each has 721 acquired angles from 0° to 360°, including the repeated end orientation. Detector readings are averaged from 560 to 140 bins for this lab. They are measured projections, not simulated views of an existing reconstruction.

The calculation uses a 2D central-plane model, nonnegative SART corrections and optional neighbour smoothing. This implementation supports reconstruction experiments and method evaluation. It is not intended for clinical use. HTC2022, Meaney and colleagues (2023), CC BY 4.0.
